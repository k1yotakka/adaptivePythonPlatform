# CodeMentor — адаптивная платформа обучения программированию с AI-ментором

**CodeMentor** (PyLearn) — это веб-платформа для обучения программированию на Python с персонализированной траекторией и встроенным AI-ментором. Студенты проходят курсы и решают задачи в браузерном редакторе кода, получают мгновенную автоматическую проверку решений и подсказки от ИИ, который направляет, но **не выдаёт готовый ответ**. Преподаватели конструируют курсы и задачи, формируют группы и следят за прогрессом, администраторы управляют пользователями.

> Дипломный проект. Реализован как full-stack приложение: REST API на FastAPI, SPA на React, база данных PostgreSQL и интеграция с Google Gemini API.

## Ключевые возможности

- **Адаптивная траектория.** На онбординге студент выбирает цель и проходит скрининг-тест, который определяет уровень (beginner / intermediate / advanced). По уровню выдаётся подходящий learning path.
- **Браузерный редактор кода** с подсветкой синтаксиса, тестовым запуском и автоматической проверкой решений.
- **AI-ментор** на базе Gemini: даёт структурированный коучинг-фидбек и отвечает на вопросы, не раскрывая готовое решение.
- **Конструктор курсов** для преподавателя: курсы → модули → уроки → задачи.
- **Группы и приглашения**: вступление по invite-коду и по ссылке-приглашению.
- **Прогресс и геймификация**: streak, статистика по темам, система достижений.
- **Ролевой доступ**: студент, преподаватель, администратор — у каждого свой интерфейс.

## Архитектура

```
              ┌─────────────────────┐
              │   React SPA (Vite)  │   интерфейсы: студент / преподаватель / админ
              └──────────┬──────────┘
                         │ REST (JWT в заголовке Authorization)
                         ▼
              ┌─────────────────────┐
              │   FastAPI backend   │   /api/v1
              │  routers: auth,     │
              │  courses, tasks,    │
              │  practice, ai,      │
              │  students, groups,  │
              │  admin              │
              └───┬─────────────┬───┘
                  │             │
        ┌─────────▼───┐   ┌─────▼──────────────┐
        │ PostgreSQL  │   │  Google Gemini API │  (только подсказки)
        └─────────────┘   └────────────────────┘
```

Принципиально важное разделение: **проверка решений выполняется детерминированно** (запуск кода и сравнение вывода), а ИИ отвечает только за подсказки. Поэтому ядро платформы — уроки, задачи, проверка, прогресс — полностью работает и без ИИ.

## AI-ментор

Подсказки генерирует Google Gemini. Реализация устойчива к нестабильности внешнего API:

- На старте запрашивается список доступных моделей и выбирается лучшая из приоритетного списка (`gemini-2.5-flash` → `gemini-2.0-flash` → `gemini-1.5-flash`), выбор кэшируется.
- Повторные попытки с экспоненциальной задержкой при временных ошибках (429/503), автопереключение модели при 404.
- Промпт построен в роли **наставника**: ИИ оценивает понимание задачи и даёт коучинг по структуре (что хорошо → что исправить → следующий шаг), **без готового кода-решения**, на языке студента.

## Проверка кода и безопасность

Решения проверяются автоматически: код студента запускается в отдельном процессе, а его вывод сравнивается с ожидаемым (с допусками на повторы и хвостовой вывод). Применяются защитные меры:

- **Серверный таймаут** выполнения (5 c для тестового запуска, 10 c для проверки решений), который **не управляется клиентом**.
- **Ограничение размера вывода** — защита памяти от бесконечной печати.
- **Изолированный режим интерпретатора** (флаг `-I`): код не наследует переменные окружения и пути сервера.
- **Очистка временных файлов** после выполнения.

> Ограничение: код выполняется на том же хосте без полной песочницы. Перечисленные меры снижают типовые риски, но промышленное решение — одноразовый изолированный контейнер на каждый запуск с лимитами CPU/памяти и отключённой сетью. Это направление развития.

## Локальный запуск

### Через Docker Compose (рекомендуется)

```bash
# в корне репозитория, рядом с docker-compose.yml
# создайте .env с переменными (см. ниже), затем:
docker compose up --build
```

После старта: frontend — `http://localhost:5173`, backend — `http://localhost:8000`, Swagger UI — `http://localhost:8000/docs`.

### Вручную (без Docker)

**Backend:**

```bash
cd python-learn-backend
python -m venv venv
venv\Scripts\activate            # Windows
# source venv/bin/activate       # macOS/Linux
pip install -r requirements.txt
# создайте .env (см. ниже)
python seed.py                   # начальные данные (один раз)
python run.py                    # старт на http://localhost:8000
```

**Frontend:**

```bash
cd python-learn-frontend
npm install
npm run dev                      # старт на http://localhost:5173
```

## Переменные окружения

**Backend** (`python-learn-backend/.env`):

```
DATABASE_URL=postgresql+psycopg2://postgres:password@localhost:5432/pylearn
SECRET_KEY=your-secret-key-here
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=1440
CORS_ORIGINS=http://localhost:5173,http://localhost:5174,http://localhost:5175
ADMIN_EMAIL=admin@codementor.com
ADMIN_PASSWORD=admin123
GEMINI_API_KEY=your-gemini-api-key
```

**Frontend** (`python-learn-frontend/.env`):

```
VITE_API_URL=http://localhost:8000
```

> `GEMINI_API_KEY` получается бесплатно в Google AI Studio. Файл `.env` не коммитится в Git (указан в `.gitignore`) — секреты задаются локально и в настройках хостинга.

## Развёртывание

Проект разворачивается тремя сервисами (на примере Render):

1. **PostgreSQL** — управляемая база; строка подключения с драйвером `psycopg2` (`postgresql+psycopg2://...`).
2. **Backend** — Web Service из `python-learn-backend/Dockerfile`; переменные окружения задаются в настройках сервиса; `entrypoint.sh` сам ждёт базу, выполняет миграции и сидинг.
3. **Frontend** — статический сайт: сборка `npm ci && npm run build`, публикация каталога `dist`, переменная `VITE_API_URL` указывает на адрес бэкенда. Для SPA настраивается rewrite `/* → /index.html`.

После деплоя в `CORS_ORIGINS` бэкенда добавляется домен фронтенда.

## Дальнейшее развитие

- **Динамическая адаптивность** — пересчёт уровня и сложности по ходу решения задач, а не только на онбординге.

- **Внешнее хранилище файлов** (S3-совместимое) для аватаров вместо локального диска.
